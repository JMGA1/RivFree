Consultas útiles

          
Pegalas en el editor SQL de tu proveedor.

          
Bajadas de precio recientes
select * from rivfree.price_drops
order by changed_at desc limit 50;

          
Ofertas actuales de una tienda
select name, price_usd, old_price_usd
from rivfree.current_offers
where store = 'DFA' and on_sale
order by price_usd;

          
Historial de un producto
select o.name, c.changed_at, c.price_usd
from rivfree.price_changes c
join rivfree.offers o on o.id = c.offer_id
where o.name ilike '%sauvage%'
order by c.changed_at;

        

      

    

    

      
DATOS MANUALES
Importar, respaldar y publicar
Los archivos manuales están separados de los scrapers, por lo que una actualización automática no los reemplaza.

      

        
Exportar respaldo
Descarga todas las tiendas y publicaciones manuales en un único JSON que después podés volver a importar.
Descargar JSON

        
Paquete listo para GitHub
Incluye catálogo manual, configuración de RivFree Studio, carrusel e imágenes de assets/manual/.
Descargar ZIP para GitHub

        
Importar JSON o CSV
JSON acepta respaldos del editor. Excel: guardá la hoja como CSV UTF-8 antes de importar; .xlsx y .xls no se leen directamente. CSV admite coma o punto y coma, crea tiendas nuevas y permite catálogos completos con encabezados como tienda,nombre,precio_usd,categoria,fuente_tipo,fuente_url.

        
Imágenes sin usar
Protege imágenes de productos, diseño, carrusel y copias de seguridad.
