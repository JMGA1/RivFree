# Actualización de rendimiento y experiencia

- Las peticiones usan la caché HTTP normal. El catálogo mantiene una URL versionada; meta.json sigue consultándose respetando las cabeceras HTTP del servidor.
- IndexedDB guarda también productos normalizados, grupos, claves de migración y vocabulario. Solo se recalculan cuando cambia el catálogo o PREPARED_CATALOG_VERSION. Si el navegador elimina la caché o no permite guardarla, el procesamiento sigue funcionando.
- Corazón en la esquina superior derecha; imagen abre un diálogo ampliado. Título enlaza a la publicación original de la oferta mostrada. El comparador permite guardar cada oferta de cada tienda y elegir cantidad.
- Los favoritos generales siguen calculándose con el menor precio; los favoritos de una tienda respetan esa oferta. La lista y el enlace compartido conservan las cantidades.
- Inicio con todas las tiendas y orden alfabético. Ofertas sigue disponible como filtro y orden opcional.
- Búsqueda con lupa y vista enfocada en resultados: oculta carrusel, descubrimientos y más consultados hasta limpiar la búsqueda.
- Aviso de disponibilidad discreto, campos móviles con tamaño mínimo de 16 px para evitar el zoom automático de iOS, controles táctiles y bloqueo del fondo al abrir diálogos.

## Instalación
Reemplazar los archivos del proyecto con este contenido, incluyendo product-details.js. Conservar el directorio .git propio. Publicar mediante el flujo habitual. La versión del service worker y de los recursos fue actualizada.
